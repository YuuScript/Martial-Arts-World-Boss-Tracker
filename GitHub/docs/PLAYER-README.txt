MARTIAL ARTS WORLD TRACKER V1.3.1
By Yuu

START HERE
1. Extract the entire ZIP (right-click > Extract All).
2. Double-click Martial Arts World Tracker.exe.
3. Open Roblox, then return to the game to start scanning.

No Python or installer is required. Keep _internal beside the EXE.

CONTROLS
Index: pin bosses, edit names/colors, or set a timer.
Ctrl + Alt + T: lock / unlock. Use Exit on the unlock control to quit.
Presets: switch your saved tracker selections.
Reset: clear timers when you change servers.
Green indicator: active. Yellow: game is not focused.

Timers start at Need entry. The app reads visible game text; fog and small
text can take longer. Scanning targets a new capture every half-second.

YOUR DATA
Settings are saved beside the EXE in settings.json. Keep the app somewhere
writable, such as Documents. Close the app before copying settings.json to
a newer version. Do not include your settings when sharing this download.
