# V1.3.1

## Download

Download **Martial-Arts-World-Tracker-V1.3.1-Windows.zip**, extract the entire ZIP, and double-click **Martial Arts World Tracker.exe**. No Python installation is needed.

## Included

- New gold-and-jade dragon clock logo and Windows app icon.
- Clean player folder with one executable and its required support files.
- A 50-entry boss library with fresh timers and three initially pinned trackers.
- V1.3's independent half-second capture pipeline and immediate matched-result updates.
- The latest Qiongyu, Patriarch Lou Kunshan, and Stair-Bell Warden defeat messages.
- MIT-licensed source and included third-party notices.

The HUD layout, resize behavior, timer rules, and presets features are retained. No personal settings, presets, logs, or game screenshots are included.

Existing users: close the tracker and copy your own `settings.json` into the new extracted folder before starting it.
